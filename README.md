# Learning & Experimentation Sandbox

Just keeping it real: this isn't some production-ready enterprise framework or a polished open-source product. This repository is basically my personal sandbox and learning dump. I put this together purely to practice, test things out, break stuff, and figure out how different programming concepts actually work under the hood.

If you stumbled across this, keep in mind it's a work-in-progress playground meant for self-education and experimenting with code.

## What's Actually in Here?

Instead of pretending this is a massive structured application, here is a honest breakdown of the main areas and concepts you'll find floating around:

### The C++ Logic & Core Practice
A big chunk of this repo is written in C++. I use this part to mess around with core programming logic, data structures, memory management, and performance-heavy stuff. It's where I try to implement algorithms from scratch, test out object-oriented principles, and see how far I can push execution speed without things crashing.

### Low-Level & Assembly Experiments
Because I wanted to understand what's actually happening at the hardware level, there are some raw Assembly snippets and low-level routines here. It's definitely not pretty, but writing and looking at assembly helps demystify registers, CPU instructions, and how high-level code translates down to the metal. 

### Software Engineering & Modular Thinking
I also use this space to practice breaking down code into manageable pieces rather than writing massive spaghetti scripts. You'll see different sections handling specific logic tasks, data parsing, and helper utilities. It's all about figuring out clean separation of concerns and keeping things organized as a project grows.

## Why Does This Exist?

No hype, no corporate standards, and no grand vision—just a simple code journal. I built this to:
* Get more comfortable writing and debugging C++ and Rust,
* Stop being intimidated by low-level stuff and look closely at Assembly.
* Practice writing cleaner, modular code instead of just making things work by accident.
* Have a place to throw random code snippets, test ideas, and learn from my own mistakes.

Feel free to look around, copy anything useful if it helps you learn, or judge the messy code—it's all part of the process!
